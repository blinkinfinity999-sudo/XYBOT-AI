## 🌟 Overview

**XYbot AI** is a sleek, web-based platform designed to deliver smooth AI-powered interactions with a modern UI aesthetic. Featuring vibrant cool-cyan to deep-violet gradient styling, fast response times, and seamless responsive design across desktop and mobile devices.

---

## ✨ Features

- 🎨 **Neovis Glowing UI:** Custom dark-mode aesthetic with smooth animated gradient text effects.
- 🚀 **Fast Deployment:** Built for quick hosting across modern platforms like Render, Vercel, and Google Sites.
- 📱 **Fully Responsive:** Optimized layouts for mobile, tablet, and desktop viewports.
- 🛠️ **Developer Friendly:** Clean project structure and lightweight code footprint.
